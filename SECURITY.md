# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of The Book Club seriously. If you discover a security vulnerability, please do NOT report it publicly in an issue.

Please report security issues by contacting the repository maintainers directly or creating a private security advisory through GitHub.

We will acknowledge your report promptly and provide an estimated timeline for remediation.
